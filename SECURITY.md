# Security Policy

This repository is a fork of [fastapi/full-stack-fastapi-template](https://github.com/fastapi/full-stack-fastapi-template).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/fastapi/full-stack-fastapi-template/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
